本周主线不是「又一个更强模型」，而是谁来选模型、Agent 在哪里跑、PR 生命周期里人还要站多深。GitHub 用 Fusion + 云 Session + Agentic Workflows 把这三件事一次性推到了生产可用；Cursor / Claude / Vercel 则在同一方向上补齐「Agent 当代码管」。

01 今日头条 GitHub Universe

Copilot Fusion 正式 GA：别再手选模型了

GitHub 让 Copilot Fusion 对全计划开放：你选努力程度（Standard / High / Max），系统按推理、写码、调试、工具调用自动路由与编排模型。

  • 官方称 Fusion Max 在 Artificial Analysis Coding Agent Index 上接近 Claude Opus 5.5 Max，成本约一半、单任务耗时约少 40%。
  • 付费计划限时享 Fusion 模型费用约 30% 折扣——适合拿真实工作负载做一周账单对照。
  • 「选哪个模型」正在变成「愿意花多少算力」的产品问题。

行动：若团队还在靠人手切模型，本周用 Fusion 跑一批真实 PR / 重构任务，对比质量和账单。

来源： GitHub Universe 2026 · TopFive 10/29

02 工作流 VS Code

云端 Session + Agent Host：Agent 不再绑在你的编辑器窗口上

Universe 发布把「会话连续性」做成默认体验：手机站立会启动云 Agent，桌上 VS Code 接管，午饭在 github.com 查看——同一 session 跨客户端接力。

  • Agent Host 把会话从单个 VS Code 窗口解耦，关文件夹 / 关窗口仍可后台跑。
  • 支持 Remote SSH / Dev Tunnel：Agent 可跑在另一台机器上。
  • 实验性 Computer Use：Agent 可操作本机桌面应用（需逐应用授权）。
  • 开放 Agent Host Protocol（AHP），可用 TS / Rust / Go 等自建客户端接入同一会话。

行动：评估是否要把长任务迁到 cloud session；企业侧先确认 Computer Use / Marketplace 策略。

来源： Copilot in VS Code Changelog

03 数据信号 Octoverse

Agent 发起的 PR 已超 40%：交付链路真的换了

GitHub Octoverse 称 9 月由 Agent 发起的 Pull Request 占比超过 40%（3 月约 17%）。同时 Agentic Workflows GA、Agent Merge 进入 PR 页，开始自动修 CI 失败与合并冲突。

  • Agentic Workflows：自然语言 Markdown 编译成标准 Actions YAML，复用现有 runner 与策略。
  • Agent Merge：在 PR 上监视并修复 blocker，可与 auto-merge 叠加。
  • 「人审意图、Agent 收尾」从实验变成可治理的默认选项。

行动：给一个低风险仓库试点 Agentic Workflows + Agent Merge；先锁只读默认与防火墙策略，再谈全仓开启。

来源： AgentMaps Oct 2026 · The Next Web

04 模型 Google

Gemini 4 Carbon：最强模型先给安全方，开发者暂不可用

Google 称 Carbon 为其最强模型，并优先开放给部分网络安全防护方；普通开发者与消费者尚无 API。SEC-bench Pro 88.2%、CWE-bench 71% 等数字显示其面向漏洞发现与修复。

  • 引入价约 $2 / $10 per M tokens；正式价预期更高（报道约 $4 / $20）。
  • 「榜首模型先给防御方」成为新发布范式——能力越强，开放越慢。
  • 日常工程仍应继续基于 Gemini 4 Argon 做规划。

行动：安全团队可关注 Fairwind / 防御方准入；应用团队先别把路线图绑在 Carbon 上。

来源： TopFive · The Neuron

05 生态 Agents-as-Code

Agent 当代码管：Cursor SDK、Glean Headless、Vercel fx

「在 Dashboard 里写 Prompt」正在被「文件夹 + 评测 + CI + 触发器」取代。Cursor Agent SDK 已 GA；Glean 支持在 Claude Code / Cursor / Codex 里 headless 构建；Vercel 开源 coding agent fx 已内置进 T3 Code。

  • Cursor：用 instructions.md + typed tools + MCP 定义 Agent，可对 PR/CI/Slack/cron 唤醒，可用 agent-sdk eval 评测。
  • Glean：在 IDE 旁写 spec.yaml，发布到同一受治理运行时。
  • fx × T3 Code：Supervised / Auto 模式，跨 web / desktop / mobile 管 coding agent。

行动：把现有 review / triage bot 迁到「可版本化的 Agent 定义」；至少加一条基于真实 PR 的回归评测。

来源： Programming the Loop · Drop Agentic

06 成本 OpenAI

GPT-6.1 Terra：半价 Computer Use，适合高吞吐自动化

OpenAI 发布面向 computer use / 视觉推理 / 写作的快速便宜模型，API 约 $1 / M input，Terminal-Bench 4.0（max）约 50.3%，约为上代 Terra 的两倍。

  • 已进入 ChatGPT Work 与 Codex（付费档）。
  • 1.05M 上下文；工具调用走 Responses API。
  • 最难编码任务官方仍建议 GPT-6.1 Sol 或 GPT-6 Astra。

行动：重新核算搁置中的 UI / 表单自动化 Agent 成本；硬核 coding 仍保留更强模型预算。

来源： Programming the Loop · 10/27

07 可靠性 Claude Code

长会话与无人值守：Claude Code 修的是「会挂」这件事

Claude Code 2.1.311 解决超 200K token 标准上下文后被迫升 1M 的打断问题（改为 compact 后继续），并修复 MCP 晚连、不可重试请求死循环，以及自托管 runner 的 idle hold。

  • 对过夜跑、CI runner、多 subagent 任务更关键。
  • 与 GitHub 云 Session、Cursor 触发器同一主题：无人值守必须先不挂。

行动：跑 Claude Code 长会话 / self-hosted runner 的同学直接升级；检查是否有因假重试而空烧的任务。

来源： Programming the Loop

本周建议盯的三件事

  1. 把「选模型」改成「选努力程度」——用 Fusion（或等价路由）做一周真实任务 A/B，用账单和质量说话。
  2. 给 Agent 一条可治理的交付路径——从 Agentic Workflows / Agent Merge / Cursor SDK 里挑一个试点，先覆盖 CI 失败修复或 PR triage。
  3. 别把路线图赌在「未开放的榜首模型」上——Carbon 式发布会越来越多；产品与成本规划仍应建立在可调用的模型上。
